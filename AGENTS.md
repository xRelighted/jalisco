# Instrucciones del repositorio Jalisco

## Publicación de cambios solicitados

Cuando el usuario pida un cambio en este repositorio, trabaja el cambio completo, ejecútale las verificaciones apropiadas y publícalo en `main` de `xRelighted/jalisco` sin pedir confirmación rutinaria para cada commit o push. Después del push, verifica que el SHA remoto coincida con el commit publicado y comprueba el despliegue automático cuando sea posible.

Esta preferencia se limita a cambios que el usuario solicitó para este repositorio. No autoriza trabajo no pedido, cambios en otros repositorios, force-push, eliminación de datos, cambios de permisos/seguridad/facturación ni otras acciones importantes o irreversibles. Respeta siempre bloqueos de permisos, aprobación explícita de GitHub, políticas de rama protegida y conflictos remotos; si requieren una elección o autoridad adicional, detente y consulta.

## Regla anti-slop

Antes de añadir badges, copy, animaciones o recursos decorativos, verifica que sean datos reales y sustentables o que ayuden al cliente a pedir, reservar o llegar. No afirmar popularidad sin datos de ventas; si la selección es editorial, identificarla como recomendación de la casa. No agregar decoración sin función ni reemplazar activos auténticos por ilustraciones genéricas que aparenten ser información real.
