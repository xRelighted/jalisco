# Jalisco Mexican Grill

Sitio vitrina para Jalisco Mexican Grill, restaurante en Lambaré, Paraguay.

## Stack

React 19, Vite, TypeScript, Tailwind CSS 4, React Router y Framer Motion.

## Desarrollo local

```bash
npm install
npm run dev
```

## Build y previsualización

```bash
npm run build
npm run preview
```

Vercel utiliza el preset Vite, publica `dist/public` y reescribe las rutas de la aplicación a `index.html` para que las páginas carguen directamente y funcionen al refrescar.
